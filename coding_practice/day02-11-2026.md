What is Linux? (DevOps Beginner Lesson)
Linux is an operating system that manages a computer's hardware, memory, files, applications, and processes.

In simple words, Linux helps a computer run programs and allows you to control what the computer does.

You may already know Windows. Linux performs many of the same basic jobs, but it's 
widely used for servers, cloud infrastructure, containers, and DevOps automation.
