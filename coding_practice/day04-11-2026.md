1. Zombie process
A zombie process is a process that has already finished running, but its entry still exists in the process table.
A parent process starts a child process.
The child finishes its work and exits.

 2. Orphan process
 An orphan process is a process that is still running after its parent process has exited.
 A parent process starts a child process.
 The parent exits.
 The child is still doing its work.

2. What is echo?
The echo command prints text or variable values in the terminal.
3. Absolute path
   An absolute path gives the complete location of a file or directory, starting from the root directory / in Linux.
  Relative path
  A relative path tells Linux where a file or directory is located from your current working directory.
