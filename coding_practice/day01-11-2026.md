What is an IP address?
IP stands for Internet Protocol. An IP address is a numerical address used to identify a device or 
network interface and help deliver data to the correct destination across a network

There are two main IP versions:
- IPv4 — for example, 192.168.1.10
- IPv6 — for example, 2001:db8::1
Others also have like s
Loopback IP, Static IP, Dynamic IP

what is DNS?
DNS stands for Domain Name System.

DNS converts a domain name, such as google.com, into the IP address or other
 destination information needed to reach a service.
================================
Types of domain names

Top-Level Domain (TLD) ex: .com, .org, .net, .in, .io
Second-Level Domain (SLD)  example: in google.com, google is the second-level domain and .com is the TLD.
Subdomain 
A name added before the main domain to identify a particular service or environment.

Examples:
- api.example.com
- dev.example.com
- admin.example.com
